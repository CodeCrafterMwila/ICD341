# ICD341 - Lab 16

## Project Title
Reproducibility, Notebook Hygiene and Project Packaging

## Description
This lab explores important practices in statistical computing,
including reproducibility, notebook organisation, exporting
Jupyter notebooks and Python project packaging.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- PyTorch
- Jupyter Notebook

## Exercises Completed
1. Setting random seeds.
2. Testing reproducibility.
3. Notebook hygiene.
4. Exporting Jupyter notebooks to HTML.
5. Python project packaging.
6. Managing project dependencies.
