# ICD341 – Lab 16

## Project Title
Reproducibility, Notebook Hygiene and Project Packaging

## Description
This lab explores important practices in statistical computing, including reproducibility, notebook organisation, exporting Jupyter notebooks and Python project packaging.

It also includes a practical maize production analysis project demonstrating data generation, descriptive statistics and visualisation.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- PyTorch
- Jupyter Notebook
- nbconvert

## Exercises Completed
1. Setting random seeds in Python, NumPy and PyTorch.
2. Testing reproducibility using identical random sequences.
3. Applying notebook hygiene practices.
4. Exporting Jupyter notebooks to HTML.
5. Organising a Python project.
6. Managing project dependencies.
7. Generating and analysing maize production data.
8. Creating and saving a histogram.

## Installation

From the ICD341 repository root, install the required dependencies using:

```bash
python -m pip install -r labs/requirements_lab16.txt
```

## Running the Maize Analysis

From the ICD341 repository root:

```bash
python Maize_Production_Project/src/analysis.py
```
